Reference information for s9 task management.

**For workflows:** Use skills (task-create, task-query, task-claim, task-update, task-close).


## Task ID Format

Auto-generated: `PREFIX-PRIORITY-NUMBER`

**PREFIX** (3 letters): Role code (ENG, OPR, DOC, etc.)

**PRIORITY** (1 letter): C=Critical, H=High, M=Medium, L=Low

**NUMBER** (4 digits): Global counter 0001-9999

**Examples:** `ENG-H-0037`, `OPR-C-0003`, `DOC-M-0142`

IDs are auto-generated by `s9 task create` - you cannot specify custom IDs.


## Status Values

**TODO:** Task created but not started (auto-set on creation) → UNDERWAY

**UNDERWAY:** Actively working on task → COMPLETE or ABORTED

**COMPLETE:** Finished successfully (terminal)

**ABORTED:** Cancelled, won't be completed (terminal)

**Note:** No BLOCKED, PAUSED, or REVIEW statuses. Document blockers/pauses in task notes.


## Priority Values

**CRITICAL:** Security vulnerabilities, data corruption, blocking all work, production outages (immediate action).

**HIGH:** Key features for milestone, P1 bugs, technical debt causing problems, required for next phase (do soon).

**MEDIUM:** Enhancements, minor features, code quality improvements, non-urgent bugs (within weeks).

**LOW:** Polish, documentation updates, minor improvements, nice-to-haves (when time permits).

## Task Lifecycle

**Creating/Claiming:**
- `s9 task create` → TODO
- `s9 task claim` → TODO → UNDERWAY

**Working:**
- `s9 task update` → UNDERWAY → UNDERWAY

**Finishing (terminal):**
- `s9 task close --status COMPLETE` → UNDERWAY → COMPLETE
- `s9 task close --status ABORTED` → UNDERWAY → ABORTED

**Typical flow:** `TODO → UNDERWAY → COMPLETE`


## Director CLI Reference

> **Agents do not use these commands.** This section documents the `s9` CLI for the Director's reference only.

**Finding work:**
```bash
s9 task list --role YourRole --status TODO
s9 task list --priority CRITICAL,HIGH --status TODO
s9 task mine --mission MISSION_ID
```

**Working on tasks:**
```bash
s9 task claim TASK_ID --mission MISSION_ID --role ROLE
s9 task update TASK_ID --status UNDERWAY --notes "Progress"
s9 task close TASK_ID --status COMPLETE --notes "Done"
```

**Creating tasks:**
```bash
s9 task create --title "Title" --description "What and why" \
  --role Engineer --priority HIGH --category "Category"
```

**Viewing:**
```bash
s9 task show TASK_ID
s9 task report --format markdown
```
