## Technical Notes

- Textual 8.x: DataTable cursor event is `RowHighlighted`, not `CursorMoved`
- Textual 8.x: cursor navigation uses `action_cursor_down()` / `action_cursor_up()` (not `action_scroll_cursor_*`)
- `DataTable.get_row_at(row_index)` returns a list of cell values — first column is the ID
- `_render_content` conflicts with an internal Textual `Widget` method name — renamed to `_build_content` in EpicFullPage
- Epic file notes sections are escape-hatch rendered (replace `[` with `\[`) to avoid markup injection
