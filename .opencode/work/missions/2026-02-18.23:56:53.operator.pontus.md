## Technical Notes

- **Do NOT use `@attach_settings(SiteNineSettings)` in CLI commands** — typer crashes on startup
- Pattern: instantiate `SiteNineSettings()` inline inside the function body
- After any `src/` changes: `uv tool install --reinstall -e /path/to/site-nine`
- ADR-013 instruction message format: role+persona / role-only / neither — each ends with "Initialize your mission with the mission-start skill."
- Interactive summon uses `os.execvp`; desk mode uses `subprocess.Popen`
