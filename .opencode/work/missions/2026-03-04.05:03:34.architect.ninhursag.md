## Technical Notes

### Key Design Decisions in ADR-015

1. **Worktree path**: `<repo-root>/../.s9-workers/<mission-id>/` — outside the repo to avoid git noise
2. **Branch name**: `worker/<mission-id>/<role-slug>` — namespace makes worker branches easy to identify
3. **Symlinks**: `.opencode/data/` and `.venv/` symlinked to main worktree; other `.opencode/` dirs use
   the worktree's own checked-out copy
4. **`find_opencode_dir()` is unchanged**: walks up from CWD, finds `.opencode/` in the worktree naturally
5. **Isolated flag default `true`**: read-only workers can opt out with `isolated: false`
6. **Branches NOT auto-deleted at worktree removal**: Admin reviews worker commits before discarding
