## Technical Notes

- `s9 mission resume` uses `subprocess.run` (not `os.execvp`) to launch OpenCode, so the
  session does not replace the calling process. This is correct for the resume flow.
- The auto-dismissal plugin limitation: async is not supported in Node.js `process.on('exit')`
  handler, so suspension only fires on SIGTERM/SIGINT, not on `process.exit(code)` calls.
  This covers the most common case (window close sends SIGTERM to the terminal process).
- Pre-existing test failures (`deleted_at` column missing) are a schema migration issue
  unrelated to this mission's work.
