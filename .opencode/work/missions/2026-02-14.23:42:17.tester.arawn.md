## Technical Notes

### Key Discoveries
1. **Epics table schema**: Has no `status` column — only `status_details` (free-form text)
2. **`_get_current_mission_id()`** returns most recent active mission by `start_time DESC`; non-deterministic with identical timestamps — fixed by giving missions distinct start times
3. **`format_json_response()`** returns `{"data": ..., "timestamp": ...}` with NO `"success"` key
4. **Self-send prevention**: `send_conversation_message` raises `InvalidParticipantError` if `from_mission_id == to_mission_id`
5. **15 pre-existing test failures** in `test_cli_task.py` (TestClaimEpicScoping, TestMissionScoping, TestTaskNewCommand, TestMutualExclusivity, TestRoleMapping) — not caused by our changes
