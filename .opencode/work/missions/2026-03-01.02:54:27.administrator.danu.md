## Technical Notes

**Datetime Bug Details:**
- SQLite's datetime() function normalizes timestamps to `YYYY-MM-DD HH:MM:SS` format
- Without normalization, string comparison uses lexicographic ordering which fails when formats differ
- The 'T' separator in ISO-8601 timestamps causes incorrect comparison results
- Solution: Always wrap datetime columns with `datetime()` function in SQL comparisons
