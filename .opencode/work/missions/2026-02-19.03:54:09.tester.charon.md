## Technical Notes

### Patching dynamically-loaded modules
When tools are loaded via `importlib.util.spec_from_file_location`, each module
gets its own namespace. Names imported with `from x import y` are bound at load
time. Standard `patch('module.path.name')` only updates the source module — not
the copy in the loaded tool's namespace. Use `patch.object(loaded_mod, 'name')`
instead.

### Schema gaps (as of 2026-02-19)
`schema.sql` does not include:
- `blocks` table (used by `BlockManager` / `task_claim` tool)
- `deleted_at` column on `handoffs` (used by `HandoffManager` soft-delete)

The test fixture applies these via raw SQLite DDL after `initialize_schema()`.
These should be added to `schema.sql` or a migration.
