## Summary

Designed and shipped the `status_queue` worker→director toast notification system. Workers push
short status messages via the `push_status` tool; the `site-nine.ts` OpenCode plugin pops and
surfaces them as TUI toasts on every `session.updated` event in the interactive director session.
Desk-mode worker sessions are automatically skipped via `desk_mode_active` DB flag check.
Also fixed model ID references (4.5→4.6), added stale-queue flush on `s9 summon`, and removed
the superseded `plugin_inbox_check.py`.
