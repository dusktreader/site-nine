## Technical Notes

**Architecture:**
- Follows ADR-013 design: polling loop runs OUTSIDE agent context
- Uses site-nine messaging system (MessageManager) for unread message detection
- Preserves OpenCode session context via `--session` flag
- Each message invocation is independent (process, mark read, exit, resume later)

**Key Implementation Details:**
- Default poll interval: 30 seconds (configurable via `--poll-interval`)
- Priority ordering: CRITICAL=0, HIGH=1, MEDIUM=2, LOW=3
- Message filtering: Excludes own messages from processing
- Timeout handling: 5min for initialization, 10min for message processing
- **SIGTERM Handling**: Gracefully disables desk mode, ends mission via mission-end skill
- **Two implementations**: desk-worker.py (full-featured) and desk_worker_wrapper.py (lightweight)

**Database Schema Fix:**
