# Site-Nine Specific Development Files

This directory contains documentation and configuration specific to **developing site-nine itself**.

These files are NOT part of the generic OpenCode infrastructure and would NOT be included in projects that use
site-nine.

  SQLAlchemy, Jinja2)
- **[`development/SITE_NINE_DEV.md`](./development/SITE_NINE_DEV.md)** - Site-nine specific development patterns,
  broken command reporting, testing, and project structure
